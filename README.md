# Azure Cloud Security Engineer Project

## Overview
Enterprise-grade Azure cloud security and DevSecOps implementation project demonstrating secure infrastructure design, AKS security, CI/CD hardening, monitoring, and disaster recovery strategies.

## Technologies
- Microsoft Azure
- AKS
- Azure DevOps
- GitHub Actions
- Terraform
- ARM Templates
- Azure Monitor
- Azure Key Vault

## Features
- Secure CI/CD pipelines
- AKS RBAC and network policies
- Terraform-based IaC
- Zero-downtime deployments
- AI-driven anomaly detection
- Multi-region DR architecture

## Setup
```bash
terraform init
terraform apply
```
